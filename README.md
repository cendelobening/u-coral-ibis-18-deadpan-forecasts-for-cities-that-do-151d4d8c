A single deadpan weather forecast for the invented city of Mirewick, written
like a straight-faced TV meteorologist reading it off the map.

Run `python3 main.py` and it writes one line to `entry.txt` inside
`$MAKEFUN_OUTPUT_DIR` (default `/output`).

Entry for the [make.fun bounty](https://make.fun/bounty/u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c).
